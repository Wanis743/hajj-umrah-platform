# Production SLO / Performance Budget

Targets:
- Command Center p95 <= 500ms for snapshot RPC on representative production-sized data.
- Booking transaction p95 <= 300ms.
- Search p95 <= 400ms.
- Standard reports p95 <= 2s.
- Availability target >= 99.9%.
- RPO <= 15 minutes.
- RTO <= 60 minutes.

These are release targets and must be measured in staging/production-like infrastructure before certification.
