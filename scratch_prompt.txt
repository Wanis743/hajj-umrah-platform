This is an absolute rule.

## `any = 0`

Not:

* zero new any
* zero in frontend
* zero in core services

# ZERO EXPLICIT `any` IN THE ENTIRE REPOSITORY

Including:

* src
* scripts
* Supabase functions
* Edge Functions
* tests
* utilities
* configuration TypeScript
* data contracts
* generated wrappers where controllable

```ts

```

```ts

```

```ts

```

```ts

```

```ts

```

```ts

```

```ts

```

Use proper domain types.

Use:

* discriminated unions
* generic types
* unknown with type guards
* schema validation
* generated database types
* explicit DTOs
* explicit RPC result types
* domain objects
* branded IDs where useful
* Zod or equivalent runtime schemas where appropriate

Do not replace `any` with:

```ts
unknown as SomeType
```

everywhere merely to silence TypeScript.

That is not the goal.

The real goal is:

# Correct type contracts.

Create a repository-wide automated gate:

```text
NO_ANY_GATE
```

The gate must fail on any newly introduced explicit `any`.

Run it against the entire repository.
